# MiniERP

A simple desktop-based **Enterprise Resource Planning (ERP) system** built with **C# and .NET**.

MiniERP is designed to help businesses manage essential records such as **companies, users, employees, customers, suppliers, products, and departments** in one centralized system.

### Tech Stack

* C#
* .NET
* Windows Forms
* Entity Framework Core
* SQL Server

> Developed for educational purposes.
